# Семейный квиз

Один статический сайт с двумя режимами для семейной игры:

1. **Квиз: 7 предметов** — классическая доска-квиз с вопросами за 100, 200 и 300 очков и двумя командами.
2. **Угадай момент** — линейная игра из 10 фильмов: сначала искажённая пародия на афишу, затем 4 варианта названия, после ответа — оригинальный постер.

Всё находится в одном файле `index.html` (HTML + CSS + JS), изображения лежат в отдельной папке `images/`. Сборка и зависимости не нужны.

## Как открыть

Просто откройте `index.html` в браузере. Либо запустите локальный сервер:

```bash
python -m http.server 8000
```

и зайдите на `http://localhost:8000`.

## Общие правила для команд

- Две команды с видимым счётом; имена можно менять прямо в панели сверху.
- В панели есть переключатель **«Очки → …»** — им можно направить очки другой команде. В окне вопроса есть два отдельных выбора: **«Отвечает»** и **«Начислить очки»**.
- Клавиши `1` / `2` выбирают отвечающую команду, `Q` / `W` — команду, которой начисляются очки.
- Кнопки `−` и `+` в панели меняют счёт именно команды, выбранной как получатель очков. Счёт не уходит в минус.
- Кнопка «Сбросить» обнуляет счёт, «Начать заново» создаёт новую игру.

## Режим 1 — доска-квиз

- 7 предметов: математика, химия, литература, русский, физика, история, география.
- В каждой теме по три вопроса: **100 / 200 / 300** очков. Всего 21 вопрос.
- Откройте клетку, нажмите «Показать ответ», затем оцените ответ: «Верно» или «Ошибка».
- Верный ответ добавляет цену клетки получателю очков, ошибка — списывает. Клетка остаётся с отметкой команды.

## Режим 2 — «Угадай момент»

- Это не доска 5×5, а последовательный раунд из **10 вопросов**.
- На каждом шаге показывается искажённая пародия на афишу (`images/posters/*-parody.jpg`) без названия, предлагаются 4 варианта «Что за фильм?», а после ответа открывается оригинальный постер и короткая справка.
- Верный ответ даёт **+100** очков выбранной команде, неверный — **−100**. Можно отвечать одной командой, а очки отдать другой.
- Прогресс, ответы и счёт сохраняются в `localStorage`; игру можно продолжить после перезагрузки.
- Клавиши `A S D F` выбирают вариант, `Enter` ведёт к следующему фильму, `Esc` возвращает на главную.

## Общее

- Счёт и имена команд общие для обоих режимов и сохраняются в `localStorage` (ключ `roditel.quiz.v3`; данные старой версии переносятся автоматически).
- Кнопка звука в шапке включает/выключает эффекты; конфетти и анимации уважают `prefers-reduced-motion`.
- Все клетки и карточки имеют одинаковый формат, переходы между режимами идут через главную.

## Как поменять вопросы

Данные лежат в начале `<script>` в `index.html`.

### Вопросы для доски

Массив `SUBJECTS`. У каждого предмета есть `id`, `title`, `icon`, `color` и `questions` — ровно три вопроса:

```js
['Текст вопроса', 'Правильный ответ', 'Короткая справка после ответа']
```

Цены задаются массивом `PRICES_SUBJECT = [100,200,300]`.

### Афиши

Массив `MOMENTS`. У каждого фильма — `id`, `title`, `year`, `accent`, `parody`, `poster`, `options` и `note`:

```js
{
  id:'captive',
  title:'Кавказская пленница',
  year:'1967',
  parody:'images/posters/captive-parody.jpg',
  poster:'images/posters/captive.jpg',
  options:['Кавказская пленница','Бриллиантовая рука','Операция «Ы»','Иван Васильевич меняет профессию'],
  note:'Короткая справка после ответа'
}
```

Верный вариант должен быть **первым** в `options`: перед показом массив перемешивается. Очки за один вопрос задаются константой `MOMENT_PRICE`.

## Картинки

- 20 файлов в `images/posters/`: 10 оригинальных афиш и 10 локально искажённых пародийных версий, все 600×900 JPEG.
- 25 прежних кадров в `images/` сохранены как источники и архив; в текущей игре они не используются напрямую.
- Источники и лицензии перечислены в [`images/CREDITS.md`](images/CREDITS.md).
