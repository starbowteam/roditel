# Игры для родителей

Один статический сайт с двумя режимами для семейной игры:

1. **Квиз: 6 предметов** — доска с вопросами за 100, 200 и 300 очков, четырьмя вариантами ответа и двумя командами.
2. **Угадай момент** — линейная игра со всеми присланными афишами: сначала искажённая пародия, затем 4 варианта названия, после ответа — оригинальный постер.

Всё находится в одном файле `index.html` (HTML + CSS + JS), изображения лежат в отдельной папке `images/`. Сборка и зависимости не нужны.

## Как открыть

Просто откройте `index.html` в браузере. Либо запустите локальный сервер:

```bash
python -m http.server 8000
```

и зайдите на `http://localhost:8000`.

## Общие правила для команд

- Две команды с видимым счётом; имена можно менять прямо в панели сверху.
- Переключатель 🏆 в панели и выбор **«Очки»** в окне вопроса позволяют направить очки другой команде. Отвечать может одна команда, а получать очки — другая.
- Кнопки ручной настройки счёта убраны: очки меняются только через ответы.

## Режим 1 — доска-квиз

- 6 предметов: математика, физика, химия, русский язык, история, география.
- Цены: **100 / 200 / 300** очков. Всего 17 вопросов: по три в каждой теме, кроме истории — там два вопроса (100 и 200).
- Откройте клетку, выберите один из четырёх вариантов ответа (А, Б, В или Г). Правильный ответ и справка появятся сразу.
- Затем оцените ответ кнопкой **✅ Верно** или **❌ Ошибка** — очки начисляются выбранной команде, и окно закрывается.
- Верный ответ добавляет цену клетки получателю очков, ошибка — списывает. Клетка остаётся с отметкой.

## Режим 2 — «Угадай момент»

- Это не доска 5×5, а последовательный раунд из **14 вопросов** — все присланные пары афиш участвуют в каждом раунде (порядок перемешивается).
- На каждом шаге показывается искажённая пародия на афишу (`images/posters/parody/…`) без названия, предлагаются 4 варианта «Что за фильм?», а после ответа открывается оригинальный постер (`images/posters/original/…`) и короткая справка.
- Верный ответ даёт **+100** очков выбранной команде, неверный — **−100**. Можно отвечать одной командой, а очки отдать другой.
- Если команда ошиблась, оригинальный постер не открывается: ход переходит ко второй команде и она отвечает на тот же вопрос. Если ошибаются обе, оригинал показывается после второй попытки.
- Прогресс, ответы и счёт сохраняются в `localStorage`; игру можно продолжить после перезагрузки.
- Кнопка **«Сыграть ещё раз»** на экране результата начинает новый раунд.

## Общее

- Счёт и имена команд общие для обоих режимов и сохраняются в `localStorage` (ключ `roditel.quiz.v7`). Из версий v6/v5 переносятся только имена, счёт и звук; старые отметки и прогресс афиш сбрасываются, потому что вопросы и постеры обновились.
- Кнопка звука в шапке включает/выключает эффекты; конфетти и анимации уважают `prefers-reduced-motion`.
- Все кнопки и карточки сделаны в одном стиле, без градиентов; подсказки с клавишами убраны.
- Название сайта — «Игры для родителей».

## Как поменять вопросы

Данные лежат в начале `<script>` в `index.html`.

### Вопросы для доски

Массив `SUBJECTS`. У каждого предмета есть `id`, `title`, `icon`, `color` и `questions` — два или три вопроса (история — два, остальные — по три):

```js
['Текст вопроса', 'Правильный ответ', 'Короткая справка', ['Правильный ответ', 'Вариант 2', 'Вариант 3', 'Вариант 4']]
```

Верный вариант должен быть **первым** в списке вариантов: перед показом они перемешиваются. Цены задаются массивом `PRICES_SUBJECT = [100,200,300]`.

### Афиши

Массив `MOMENTS`. У каждого фильма — `id`, `title`, `year`, `accent`, `parody`, `poster`, `options` и `note`:

```js
{
  id:'kavkazskaya-plennitsa',
  title:'Кавказская пленница',
  year:'1966',
  parody:'images/posters/parody/kavkazskaya-plennitsa.jpg',
  poster:'images/posters/original/kavkazskaya-plennitsa.jpg',
  options:['Кавказская пленница','Бриллиантовая рука','Операция «Ы»','Иван Васильевич меняет профессию'],
  note:'Короткая справка после ответа'
}
```

Верный вариант должен быть **первым** в `options`: перед показом массив перемешивается. Очки за один вопрос задаются константой `MOMENT_PRICE`.

## Картинки

- 14 пар в `images/posters/parody/` и `images/posters/original/`: пародийные версии без текста и оригинальные афиши, все 600×900 JPEG. Все пары участвуют в раунде, порядок перемешивается.
- 25 прежних кадров в `images/` сохранены как источники и архив; в текущей игре они не используются напрямую.
- Источники и лицензии перечислены в [`images/CREDITS.md`](images/CREDITS.md).
