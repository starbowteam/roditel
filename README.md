# Семейный квиз

Один статический сайт с двумя режимами для семейной игры:

1. **Квиз: 7 предметов** — классическая доска-квиз с вопросами за 100, 200 и 300 очков и двумя командами.
2. **Угадай момент из фильма** — кино-квиз 5×5: пять тем и пять уровней сложности, 25 кадров с вопросами.

Всё находится в одном файле `index.html` (HTML + CSS + JS), кадры лежат в отдельной папке `images/`. Сборка и зависимости не нужны.

## Как открыть

Просто откройте `index.html` в браузере. Либо запустите локальный сервер:

```bash
python -m http.server 8000
```

и зайдите на `http://localhost:8000`.

## Режим 1 — доска-квиз

- 7 предметов: математика, химия, литература, русский, физика, история, география.
- В каждой теме по три вопроса: **100 / 200 / 300** очков. Всего 21 вопрос.
- Две команды с видимым счётом. Нажмите на карточку команды или клавиши `1` / `2`, чтобы выбрать отвечающую.
- Откройте клетку, нажмите «Показать ответ», затем оцените ответ: «Верно» или «Ошибка».
- Верный ответ добавляет цену клетки, ошибка — вычитает. Счёт нельзя увести в минус.
- Клетка остаётся с отметкой: синяя — ответила первая команда, розовая — вторая, серая — ошибка.
- Кнопки «Новая доска» и «Сбросить» позволяют начать раунд или обнулить счёт.

## Режим 2 — кино-квиз

- 5 тем: комедии Гайдая, классика кино, Винни-Пух, сказки и фантастика, школа и детство.
- 5 уровней: 100, 200, 300, 400 и 500 очков. Всего 25 моментов.
- В каждой клетке — локальный кадр (`images/*.jpg`), подпись или цитата поверх кадра, вопрос и четыре варианта ответа.
- Выберите команду, откройте клетку и нажмите вариант или клавиши `A S D F`.
- Верный ответ приносит очки клетки, неверный — списывает столько же.
- Варианты перемешиваются при каждом открытии, поэтому угадать с первого раза не получится.

## Общее

- Счёт и имена команд общие для обоих режимов и сохраняются в `localStorage` (ключ `roditel.quiz.v2`).
- Кнопка звука в шапке включает/выключает эффекты; конфетти и анимации уважают `prefers-reduced-motion`.
- Клавиатура: `1` / `2` — команда, `A S D F` — вариант ответа, `Enter` — показать ответ / закрыть окно, `Esc` — закрыть окно или вернуться на главную.
- Все клетки и модальные окна имеют одинаковые размеры и формат, переходы между режимами идут через главную.

## Как поменять вопросы

Данные лежат в начале `<script>` в `index.html`.

### Вопросы для доски

Массив `SUBJECTS`. У каждого предмета есть `id`, `title`, `icon`, `color` и `questions` — ровно три вопроса:

```js
['Текст вопроса', 'Правильный ответ', 'Короткая справка после ответа']
```

Цены задаются массивом `PRICES_SUBJECT = [100,200,300]`.

### Кино-моменты

Массив `THEMES`. У каждой темы — `id`, `title`, `icon`, `color`, `tagline` и `levels` — ровно пять уровней:

```js
{
  price: 300,
  img: 'images/gayday-3.jpg',
  question: 'Угадайте фильм по кадру',
  quote: 'Подпись или цитата поверх кадра',
  note: 'Короткая справка после ответа',
  options: ['Вариант 1', 'Вариант 2', 'Вариант 3', 'Вариант 4'],
  correct: 0
}
```

`correct` — номер верного варианта до перемешивания (0, 1, 2 или 3). Названия уровней задаются массивом `LEVELS`.

Чтобы добавить момент, положите JPEG размером 960×540 в `images/` и добавьте объект уровня в нужную тему.

## Картинки

Все 25 изображений сохранены локально в `images/` и приведены к одному формату 960×540 JPEG. Источники и лицензии перечислены в [`images/CREDITS.md`](images/CREDITS.md). Часть файлов — архивные кадры и иллюстрации, доступные по свободным лицензиям; кадры из современных фильмов использовать нельзя было бы без правообладателей.
